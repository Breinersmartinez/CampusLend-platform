Arquitectura hexagonal y flujo de la aplicación CampusLend

Adaptadores de entrada (driving) Dominio + puertos Adaptadores de salida (driven) Infraestructura externa
La arquitectura hexagonal (Ports & Adapters) garantiza que el dominio de CampusLend — las reglas de negocio, entidades y flujos — nunca dependa directamente de Spring, JPA ni PostgreSQL. El dominio define interfaces (puertos) y los adaptadores las implementan. Si mañana se cambia Neon DB por otro motor, solo cambia el adaptador de salida; el dominio no se toca.
